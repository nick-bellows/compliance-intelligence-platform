# Project charter

## Problem

Diligence teams need traceable screening leads and research engineers need reproducible information-extraction systems. This portfolio demonstrates a narrow, reviewable workflow without claiming to reproduce a commercial compliance product.

## In scope

- Public, authoritative sanctions data
- Synthetic screening inputs
- Explainable candidate matching
- Public legal/government corpus after licensing review
- NER, structured extraction, BM25 retrieval, API delivery, and analyst exports

## Out of scope

- Compliance determinations or legal advice
- Private-person investigations
- Adverse-media scraping
- Hidden proprietary watchlists
- Automated approval or rejection decisions
- Production identity verification

## Success measures

- Reproducible source snapshots and outputs
- Evaluated matching, NER, and retrieval behavior
- Human-readable reasons for every flagged candidate
- Tests for core transformations and API failure behavior
- Clear limitations and error analysis
